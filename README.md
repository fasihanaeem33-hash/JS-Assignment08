# JavaScript Assignment 8

This project contains five JavaScript exercises covering arrays, objects, maps, and JavaScript built-in methods.

## Project Structure

- `Q1/` - Online Store Sales Report
- `Q2/` - Student Performance Analyzer
- `Q3/` - Employee Data from an API
- `Q4/` - Store Inventory Using JavaScript Map
- `Q5/` - Student Result Object

## Questions Covered

### Q1: Online Store Sales Report
Uses `find`, `filter`, and `reduce` to:
- find the first order greater than 2000
- filter all orders above 1000
- calculate the total sales

### Q2: Student Performance Analyzer
Uses array methods to:
- increase each mark by 5
- filter passing marks (70 or above)
- find the first mark above 90
- calculate total marks

### Q3: Employee Data from an API
Uses `filter`, `find`, `map`, and `reduce` to:
- find IT employees
- find the first employee earning more than 90000
- create a list of employee names
- calculate total salary

### Q4: Store Inventory Using JavaScript Map
Demonstrates working with `Map`:
- add items
- update values
- retrieve values
- check existence
- delete entries
- display product names and quantities
- clear the map

### Q5: Student Result Object
Creates student objects and calculates:
- total marks
- percentage
- access properties using dot and bracket notation
- delete a property and display the final object

## How to Run

1. Open the respective `Qn.html` file in a browser.
2. The JavaScript file linked inside it will run automatically.
3. Open the browser console to view the output.

Example:
- `Q1/Q1.html`
- `Q2/Q2.html`
- `Q3/Q3.html`
- `Q4/Q4.html`
- `Q5/Q5.html`

- These exercises use plain JavaScript.
